This is where dropping the mono costs something real. In a proportional face 1 / l and 0 / O stop being distinguishable, and these are strings a person copies once and can never re-read. All of it lives in the admin UI (milestone 5) — so the fix is a single utility class using the browser's own ui-monospace, no webfont downloaded, no third family in the design system.
Wins
One font request fewer, a warmer and less technical feel, and chord-over-lyric that is actually more correct than the mono version was.
Costs
Metadata loses its distinct voice — everything small is now the same grey Chivo, so hierarchy has to come from weight and colour alone.
