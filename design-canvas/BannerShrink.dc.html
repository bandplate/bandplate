B3 — The block is only as wide as it needs to be

The banner shrinks to its content. A one-word confirmation is a small object; a long explanation with an action grows to a reading measure and stops. No empty space, because there is no space to be empty.

Costs: several banners in a row become ragged, each a different width, which reads as chaos rather than as economy. A short one can also stop looking like a page-level announcement and start looking like a chip.
