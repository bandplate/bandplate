Instruments — second attempt
Real icons, not mine
The previous set was twelve SVG paths I wrote by hand from imagination, and it looked like it. Withdrawn. These are from Game Icons, drawn as one family — the only set surveyed that actually covers a band. Lucide, Tabler, Phosphor and Material between them have guitar, piano, microphone and violin and no drums, trombone, flute or clarinet at all, so none of them can complete the list a roots band fields.

None renders the instrument's initials in a circle. It is a real choice, and it is also what every instrument shows the day this ships — the column is nullable and needs no backfill.
The catch — attribution
Game Icons is CC BY 3.0: usable commercially and modifiable, but it requires visible credit. For a self-deployable app that obligation passes to every deployer, so it belongs in the product — a credit line on an About or admin screen, not only in the repo. That is a decision to take deliberately rather than a detail to vendor quietly.
If that is unwelcome
Material Design Icons is Apache 2.0 with no attribution requirement, but covers only guitar, piano, microphone, saxophone, trumpet and violin — no drums, no trombone. A band's list would be half pictures and half initials, which reads worse than either alone. The honest alternative is initials for everything: complete by construction, no licence, no drawing.
