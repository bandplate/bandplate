M1 — Plain text, written properly

No HTML part at all. Fix what is actually wrong: the link on its own line, an expiry a person can read, the stray space gone, and one voice across all three messages. The plan's own decision says plain-text-first here, because deliverability matters more than styling when this is the only door.

Costs: in a client that renders HTML it looks like a system notification rather than like bandplate. There is no wordmark and no button, so the click target is a bare URL — which is what people are warned about.

"It works once, and only for the next 15 minutes" — the two facts about the link that matter, in words. The ISO timestamp said neither.

The "if you did not ask for this" line is not filler: this address is on a whitelist, so an unexpected sign-in mail means someone typed it into the login form, and saying nothing invites a support question.
