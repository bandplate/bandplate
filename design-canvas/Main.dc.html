Three faces, one rule
Each face has exactly one job and no overlap. The rule below is what keeps mono from creeping back into chrome.
Alfa Slab One
--bp-font-display
400 only. Song titles, event titles, page headings, big counts. Never a sentence, never under 17px.
Chivo
--bp-font-body
300 / 400 / 600 / 900. Everything else — prose, labels, timecode, counts, buttons, form fields. Tabular figures on for anything numeric.
Spline Sans Mono
--bp-font-mono
400 / 600. Content only, two places. See the rule — if you are reaching for it anywhere else, the answer is Chivo.
The mono rule
Mono is for text whose horizontal position carries meaning, and for strings a human transcribes character by character. That is pasted chord charts — free text already aligned with spaces, which collapses in a proportional face — and machine strings in the admin UI: service tokens, storage keys, hashes, where 1/l and 0/O must stay apart.
Not mono: eyebrows, meta lines, durations, BPM, keys, vote counts, timecode, badges, buttons, table cells. A clock is not a character grid — it needs equal-width digits, which font-variant-numeric: tabular-nums gives you in Chivo. Pair it with a fixed min-width on any value that ticks, so the layout holds regardless of font loading.

Gold is dark-theme only as an accent. In light it drops to 2.1:1 and becomes a fill and rule colour — the playhead, a progress bar, a keeper badge background — never text and never a border you need to see. The light accent role goes to burnt gold #7A4E05, which is the same hue at a lightness that clears AA. --bp-color-on-accent is fixed bone #F2E8D8 in both themes and must never be defined inside a theme block — that exact bug shipped once already.
